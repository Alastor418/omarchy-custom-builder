# Omarchy Custom ISO Studio

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Omarchy Custom ISO Studio** — это универсальный, мощный и удобный инструмент для создания полностью кастомных сборок операционной системы на базе Arch Linux.

Программа оснащена современным графическим интерфейсом на PyQt6 (в стиле Tokyo Night / Catppuccin), а также имеет запасной TUI (текстовый интерфейс) для работы на серверах или в средах без графической оболочки.

Все ваши настройки можно сохранить в единый профиль (`profile.json`) для повторного использования.

---

## Установка и запуск одной командой

Для начала работы достаточно выполнить эту команду в терминале:
```bash
curl -fsSL https://raw.githubusercontent.com/Alastor418/omarchy-custom-builder/main/install.sh | bash
```
Скрипт автоматически проверит наличие интернета, свободного места на диске (минимум 20 ГБ), установит необходимые зависимости (QEMU, PyQt6, Git, Docker и др.) и запустит Studio.

## Обзор интерфейса (Вкладки)

Графический интерфейс разбит на логические вкладки, позволяющие контролировать каждую деталь будущей системы:

### 1. Заставка, Загрузчик и Брендинг
- **Управление загрузчиком и экраном входа**: Настраивайте фоны для загрузчика Limine и экрана входа SDDM.
- **Поддержка автовхода (Autologin)**: Можно настроить автоматический вход пользователя в систему.
- **Брендинг**: Меняйте название ОС (запишется в `/etc/os-release`), имя хоста (hostname), ASCII-логотип `fastfetch` и заставку Plymouth.
- **Hyprlock**: Настройка фона экрана блокировки.

### 2. Программы и Свои Конфиги (Dotfiles Overlay)
- **Управление пакетами**: Фильтруйте и удаляйте ненужные базовые пакеты, добавляйте любые кастомные (из официальных репозиториев или AUR). Базовые зависимости Hyprland/Quickshell остаются защищёнными благодаря встроенному Smart Sanitizer.
- **Инжектор конфигов (Dotfiles)**: Позволяет добавлять свои конфигурационные файлы в будущую систему. Поддерживается управление правами (`chmod`). Например, можно сразу пробросить свои настройки Alacritty, Kitty или любые другие скрипты прямо в `~/.config/` или `/usr/local/bin/`.

### 3. Внешний вид Hyprland и Quickshell
- **Настройка Hyprland**: Изменяйте отступы (gaps), границы, радиус скругления окон, эффекты размытия (blur) и анимации.
- **Настройка Quickshell**: Позволяет задавать позицию панели (сверху/снизу), отступы, прозрачность, шрифты и радиус виджетов прямо из GUI.

### 4. Глубокий редактор файлов системы
- **Встроенный файловый менеджер и редактор кода**: Вы можете напрямую просматривать и редактировать абсолютно любые файлы в директориях сборщика.
- **Правила замены строк (Line Patching)**: Задавайте правила (в том числе с использованием регулярных выражений) для автоматической замены строк в системных файлах до начала сборки.
- **Пост-установочные chroot скрипты**: Возможность задать Bash-команды, которые будут выполнены внутри chroot-окружения вашей новой ОС сразу после её установки.

### 5. Автоустановка (Unattended / cidata)
- Настройте автоматическую установку вашей ОС (без единого вопроса). Задайте имя пользователя, пароль, часовой пояс, раскладку клавиатуры и SSH-ключи. Пароль автоматически хэшируется.

### 6. Самодиагностика и Сборка ISO
- **Профили**: Сохраняйте все свои настройки в файл `profile.json` или загружайте их для продолжения работы.
- **Синтаксические проверки**: Встроенная проверка Bash-скриптов (`bash -n`) и безопасная очистка зависимостей (Smart Sanitizer).
- **Сборка и тестирование**: Соберите рабочий `.iso` образ и протестируйте его в изолированной виртуальной машине QEMU прямо из программы (кнопка "Протестировать в QEMU").

## Как добавить свою программу и её конфиги

1. Перейдите во вкладку **"Программы и Свои Конфиги"**.
2. Впишите название пакета (например, `firefox`) в поле **Дополнительные пакеты**.
3. В поле конфигов укажите путь (относительно корня файловой системы или `~` пользователя) и содержимое.
   Например:
   ```json
   {
     ".config/firefox/profiles.ini": "[General]\nStartWithLastProfile=1"
   }
   ```
4. Если вашему скрипту нужны права на выполнение, укажите их в поле прав:
   ```json
   {
     ".local/bin/myscript.sh": "0755"
   }
   ```

## Запись на USB-накопитель

После сборки и тестирования в QEMU, вы можете записать готовый ISO-образ (находится в папке `omarchy-work/omarchy-iso/release/omarchy.iso`) на USB-флешку:
```bash
sudo dd if=~/omarchy-work/omarchy-iso/release/omarchy.iso of=/dev/sdX bs=4M status=progress
```
*Замените `/dev/sdX` на букву вашего USB-диска.*

Также вы можете использовать программы с графическим интерфейсом: **balenaEtcher**, **Rufus**, или **Caligula**.

# Omarchy Custom ISO Studio

`curl -fsSL https://raw.githubusercontent.com/Alastor418/omarchy-custom-builder/main/install.sh | bash`

Добро пожаловать в **Omarchy Custom ISO Studio** — универсальный и мощный инструмент для создания кастомных сборок операционной системы на базе Arch Linux. 
Программа оснащена современным графическим интерфейсом на PyQt6 в стиле "Tokyo Night / Catppuccin", а также имеет fallback-вариант TUI (текстовый интерфейс) для работы на серверах без графической среды.

## Особенности
* **Однострочная установка**: Запустите одну команду, и скрипт автоматически проверит место на диске (20 ГБ), интернет, установит нужные зависимости и запустит Studio.
* **Кастомизация заставки и брендинга**: Настройка Splash-экранов, Plymouth, логотипов и `os-release`.
* **Добавление программ и конфигов**: Добавляйте любые пакеты и автоматически пробрасывайте свои конфиги (dotfiles) прямо в систему. 
* **Внешний вид Hyprland и Quickshell**: Настраивайте отступы, границы, скругления, и параметры панели.
* **Глубокий редактор системы**: Встроенный файловый менеджер и редактор кода для патчинга любых строк и скриптов в будущей ОС.
* **Автоустановка (Unattended)**: Преднастройка пользователей, паролей, часовых поясов и раскладок для установки ОС без единого вопроса.
* **Самодиагностика и Сборка**: Проверка синтаксиса Bash (`bash -n`), автоматический Smart Sanitizer, сборка ISO в фоне и возможность тестирования в QEMU прямо из программы. Поддержка сохранения и загрузки профилей сборки (JSON).

## Разработка и тестирование
Для запуска тестов используйте:
```bash
pytest test_omarchy_builder.py
```
Тесты проверяют клонирование репозиториев, санитайзер скриптов, патчинг файлов и работу GUI-интерфейса в headless-режиме (без дисплея).
